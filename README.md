## Marble Run Game
I'm building a marble run machine for my Half Life project!

The idea is simple: a marble keeps moving through different ramps and slides, and instead of manually moving it back to the starting point, a motor-powered wheel takes it back up so it can run again. Basically, an automatic marble run game! 🎱

##  How does it work?

 - A small DC motor powers the cycle wheel.
- The cycle wheel is connected to the spin wheel using a rubber band.
- The spin wheel has an arc cut that helps carry the marble upwards.
- Once the marble reaches the top, it rolls down through different ramps and slides because of gravity.
- It comes back to the spin wheel, and the whole process repeats!

The goal is to make the marble keep moving automatically without having to pick it up and put it back every time.
